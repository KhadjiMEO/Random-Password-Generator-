# Random Password Generator

**Автор:** [Хаджимурат Отаров]

## Описание

Приложение для генерации случайных паролей с настраиваемыми параметрами. Позволяет выбирать типы символов, длину пароля и сохраняет историю последних сгенерированных паролей.

## Функциональность

- Настройка длины пароля (4–64 символа)
- Выбор типов символов: буквы, цифры, спецсимволы
- Генерация пароля по нажатию кнопки
- Отображение пароля в удобном поле
- Сохранение истории последних 10 паролей
- Очистка истории
- Автоматическое сохранение истории в JSON‑файл
